# ☕ DSA-Java — Data Structures & Algorithms in Java

A comprehensive collection of **Data Structures and Algorithms** implemented in **Java**, organized topic-wise for easy navigation and learning.

---

## 📁 Topics Covered

| # | Topic | Description |
|---|-------|-------------|
| 1 | **Basics and Arrays** | Fundamentals of Java and array operations |
| 2 | **Strings** | String manipulation and pattern problems |
| 3 | **ArrayList** | Dynamic arrays using Java's ArrayList |
| 4 | **Linked List** | Singly, doubly, and circular linked lists |
| 5 | **Stack** | Stack implementation and applications |
| 6 | **Queue** | Queue implementation and variations |
| 7 | **Recursion** | Recursive problem solving techniques |
| 8 | **Backtracking** | Constraint-based search (N-Queens, Maze, etc.) |
| 9 | **Divide & Conquer** | Problems solved by splitting into subproblems |
| 10 | **Searching and Sorting** | Binary Search, Merge Sort, Quick Sort, etc. |
| 11 | **Hashing** | HashMap, HashSet, and hash-based problems |
| 12 | **Binary Tree** | Tree traversals, height, diameter, and more |
| 13 | **Heaps** | Min/Max heap, priority queue problems |
| 14 | **Greedy Approach** | Greedy algorithms and interval problems |
| 15 | **Bit Manipulation** | Bitwise operations and tricks |
| 16 | **OOPS** | Object-Oriented Programming concepts in Java |
| 17 | **IMP Problems** | Important and frequently asked problems |

## 🚀 Getting Started

### Prerequisites
- Java Development Kit (JDK) 8 or above installed

### Steps

1. **Clone the repository**
   ```bash
   git clone https://github.com/SamruddhiNadgouda/DSA-Java.git
   ```

2. **Navigate to the project folder**
   ```bash
   cd DSA-Java
   ```

3. **Open any topic folder and run a file**
   ```bash
   cd "Searching and Sorting"
   javac FileName.java
   java FileName
   ```
